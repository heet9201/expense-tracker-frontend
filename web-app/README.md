# ExpenseTracker Web App

AI-Powered Budget Management & Expense Tracker MVP for Indian users.

## Features Implemented

### 1. Onboarding Flow
- Welcome Screen with multi-language selection
- Permissions Setup for SMS, Camera, and Microphone
- Profile Setup with budget cap configuration

### 2. Dashboard
- Stats Cards with spending overview
- Quick Actions for adding expenses
- Visual Analytics (Pie & Bar charts)
- Budget Status cards with color coding
- Recent Expenses list
- Smart Alerts and notifications

## Tech Stack

- Next.js 14+ (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Recharts
- Lucide React

## Getting Started

```bash
cd web-app
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
